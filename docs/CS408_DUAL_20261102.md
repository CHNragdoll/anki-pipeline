## 统一流程与来源边界

`study_exam_source.read_bank` 只读整卷题库 → `study_exam_package.source_package` 生成统一输入 → `study_catalog_import.import_package` 登记到 PostgreSQL 的 `cs408-exams` → 公共 `project_book/project_note` → `study_catalog_export.export_book` 输出 APKG 与网页。独立说明卡由通用 `study_exam_guide.add_guide` 最后追加，政治的旧固定身份及说明正文保持兼容。

2009—2015 年整卷 kind 为 `complete`，之后题卷为 `questions`。只选 `in_bank=1` 的父题，避免把整卷的独立答案记录再次当题。小问保留在原 HTML 中，不依赖空的 normalized subquestions 数组。题型显示标签通过共同配置指定，未新建一套408导出器。

2011 年答案块也关联到题面：70 个纯答案块仅留背面；其中第31题的一个块同时含续题干、四个选项与“解答”。现按明确答案段落边界拆分显示，完整原块、SHA256、分割位置和两个投影保存在 SourceRecord。无可靠边界会拒绝生成，避免丢题或泄漏答案。

原 SVG 有部分 FileProvider 未下载文件。只恢复本次引用的152个资源到一个缓存，从本地 Git blob 读取并校验 Git对象身份及源文件大小／时间。个别文件的不同 Python stat 实现有纳秒舍入差，读取阶段在同一解释器重新封存，记录与 Git index 不超过1微秒的差异；生成器仍严格检查封存大小／时间和缓存 SHA256。原件和源 Git 配置均未修改。
