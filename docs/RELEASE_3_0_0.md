## 正式版与已有证据的对应

- 运行代码和模板沿用已合并的 rc.3 / PR #3，原运行与浏览器证据见 [rc.3 范围记录](RELEASE_RC3.md) 和 [rc3-verification.json](rc3-verification.json)。APKG SHA 一致，因此此前对同一包的 Anki backend 隔离导入、身份及媒体核对仍适用于该附件。
- 当前源码四处版本需统一为 `3.0.0`；执行 `uv lock --check` 和 `PYTHONPATH=. .venv/bin/python scripts/verify_project.py`，并核对干净构建的 wheel 版本、MIT 元数据和许可证全文。完整 Python / JavaScript 检查由当前发布 PR 和 main CI 执行。
- 使用独立审查核对实际版本差异、发布资产范围及证据复用边界。正式版 PR #5 合并时，公开主分支尚未启用服务端分支保护；当时以维护者明确发布授权、发布 PR、当前 CI 和独立审查作为记录。随后维护者要求保护与逐 PR 同意，已启用规则及时间边界见 [分支保护说明](BRANCH_PROTECTION.md)。tag 不因后续规则变化而移动。
- MIT 已由 GitHub 识别为 `key: mit`、`spdx_id: MIT`。原创源码和原创文档采用 MIT；第三方词典、真题、音频、图片及依赖保留各自许可。

## 交互与兼容性范围

本次发布包含词卡正背面统一布局、词典录音选择、词形和词源、完整真题例句、题干 / 选项补全及去重计数、中英文 chunk 悬停 / 点击荧光对应、真题跳转及双向补全定位框、同内容网页预览与离线网页生成。全部功能与逐步执行命令见首页 README。

当前真题跳转默认配置为 `http://localhost:8765`，需要同机运行配套 [exam-library](https://github.com/CHNragdoll/exam-library) 服务或修改配置为自己的实际服务地址。配套接收端的本地改动不因为本仓库发布而自动发布到远端，也不自动提供手机访问电脑 localhost 的能力。

正式版本号和公开发布不扩大已有验收结论：实际 AnkiMobile / AnkiDroid 真机流程仍未验收；手机比例截图来自浏览器。现成 chunk 覆盖 15,627 / 20,178 条展示例句，缺少可靠对应的文本保持普通文字；哈希身份检查不证明每条译文语义正确。保留 rc.3 文档里的具体语义和来源限制。

## 安装与恢复

下载 APKG 后通过 Anki 的导入功能导入。更新已有重建版卡组前，使用 Anki 自身备份保留当前集合及进度；本次附件保留已核验的重建版身份，不承诺自动迁移原 V2.0 的不同模型 / GUID 排程。卡组名称由维护者指定，复习算法仍由 Anki 管理。

保留旧卡包、旧网页和原始输入。发布后的 `v3.0.0` tag 与附件不覆盖或移动；发现需要修正的运行问题时发布新版本。重新导入旧 APKG 不保证恢复全部模板或字段，用户集合恢复使用 Anki 备份。
