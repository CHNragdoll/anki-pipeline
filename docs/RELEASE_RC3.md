## 输入、兼容性与限制

- 源码仓库不含完整原词库、数据库、词典、音频、真题索引或私有审校输入。默认完整生成需要配置并准备它们；源码安装和测试不等于完整学习数据已经存在。
- `exam_library.reading_completion_path` 指定受审侧车；对应候选译文与 review 位于同目录，review 中引用的作者/独立审校证据也必须可访问且哈希一致。
- 本机配套真题功能不能用远程 `0.1.0` 版本号代替实现检查。主说明标明联动双方与实际观察状态。
- 当前命名包延续重建版身份；原 V2.0 模型/GUID 的学习进度不自动迁移。后续改名重建和覆盖导入仍需以具体包核对 deck / model / GUID、导入选项与备注字段。
- 现成 chunk 范围覆盖 15,627 / 20,178 条例句；没有可靠对应的部分保持普通文字。哈希绑定证明记录身份，不证明翻译语义正确。
- 单词音频来自本地媒体；例句右侧图标用于跳转真题原句。当前版本没有例句在线 TTS 播放入口，查看卡片不会发送例句语音请求。
- 卡组名称中的“艾宾浩斯曲线版”是用户指定名称，复习算法与排程仍由 Anki 管理。本项目不实现或声称更换 Anki 记忆算法。
- 本轮不通过生成包、截图或 PR 自动导入用户真实档案、评分或同步。手机和平板的 hover 替代点击已提供；实际 AnkiMobile / AnkiDroid 设备验收仍需单独记录。

## 发布与回滚

PR 由用户本轮明确请求。合并、tag 与 Release 状态以执行时的实际授权和 GitHub 记录为准，不复用历史 rc.1 / rc.2 的一次性批准。私人仓库的服务端保护是否生效需要现场核对；历史 403 不能当作当前检查结果。

保留旧 APKG 和网页版本；新版流水线数据库通过 SQLite 备份恢复到新路径并对账。用户 Anki 笔记和进度需要导入前的 Anki 自身备份；重新导入旧包不保证回退全部字段或模板。正式发布后的 tag 和已发布资产不原地改写，修正用新版本。
