# 红宝书发音、释义与精简导出

这份改动提供发音显示、释义纠错和按牌组导出的源码支持，不创建 Release，不改变已有刘晓艳版本的标签或附件。词表、词典原页、录音库、APKG、个人集合和本机核验中间文件不进入 Git。

## 发音和搜索

提供 `local_dictionary.accent_audio` 的词卡启用独立英美播放。英式选择剑桥/牛津，美式选择牛津/韦氏；录音须分别声明 `uk` 或 `us`。带 `英:/…/ 美:/…/` 的音标显示蓝、红播放图标，悬停或点击显示 BrE/NAmE。控件使用本项目绘制的离线 SVG。

选择韦氏而本词缺少韦氏美音时，允许使用同词牛津美音，并持续显示“美式韦氏未收录，此词使用牛津录音”。用户的韦氏偏好仍保留。选择牛津时不会自动借用韦氏。剑桥、Collins、Wiktionary、Forvo 的补录只接受明确声明的来源和口音；无合格录音时显示缺失。旧单来源词卡继续使用原控件。

这是本地已核对录音的播放和打包协议，运行卡片不会联网下载。音标是独立显示字段，不从录音的词典名推算；只有单音标或缺音标时仍保留英美播放入口，不自动填造音标。此次没有新增音标抓取、录音下载器或 TTS。

书库搜索结果保持原书顺序。输入完整 `water` 时，优先打开当前卡组内的 `water`，而不是排序在前的 `waterfall`；同词多张卡保留已选中的精确匹配项。

## 释义纠错

牛津索引跳转到根词不再授权复制根词的全部释义。大小写词条、词头明确列出的拼写变体、仅绑定某个义项的变体分别处理；找不到匹配释义时仍使用原有词表/ECDICT 缺项流程。

`anki_pipeline/definition-corrections.json` 保存小规模人工核对的修正记录、来源说明及证据 SHA-256，不包含原词典页面。修正须匹配原牛津记录 ID、词头及全文摘要；数据版本变化会要求重新核对，不把旧修正静默用于新来源。证据文件以文件名和摘要识别，本地原页留在审校目录。安装 wheel 时包含该修正表，卡片同时显示“释义来源（已核对）”。

## 只导出说明和必考词

从已经准备好的、含 `collection.anki2` 的兼容 APKG 导出；不访问 Anki 客户端，不写现有集合：

```sh
uv run python scripts/export_apkg_subset.py full.apkg required.apkg \
  --deck '2026考研英语词汇红宝书考研英语（必考词+基础词+超纲词）真题例句版::00 牌组说明' \
  --deck '2026考研英语词汇红宝书考研英语（必考词+基础词+超纲词）真题例句版::01 必考词'
```

`--deck` 必须精确指定分组名称，自动包含该分组下的子牌组。拼写错误、空选择、跨组拆分同一笔记的兄弟卡片、缺失媒体或不支持的新版压缩格式会报错。输入和已有目标文件都不会被覆盖。新版 APKG 请先用 Anki 导出兼容格式。

导出保留被选词卡的原字段、GUID、笔记/卡片 ID、due 顺序、暂停/复习状态及关联复习记录；移除其他分组和删除墓碑。共享脚本、样式和图片保守保留，未引用的录音裁除；保留的媒体逐个核对内容摘要。支持静态 `[sound:文件名]`、`src` 及脚本中的文件名引用；不支持运行时拼接音频文件名。使用这类自定义模板前应先把媒体引用改为完整文件名并自行验证。

说明卡的内容不会凭空改写。如需在说明中写精简版卡数和完整版入口，传入单独准备的 UTF-8 JSON：

```json
{
  "说明笔记的数字ID": ["原 Title", "精简版 Overview 的 HTML", "精简版 Guide 的 HTML"]
}
```

将上述键替换为真实数字 ID，然后添加 `--guide-fields guide-fields.json`。只允许更新字段结构恰为 `Title/Overview/Guide` 的已选说明笔记，且 Title 必须与原文一致；不允许以此接口修改词汇字段。HTML 作为可信维护者提供的卡片内容保留，请自己审核其中的文字和链接。精简说明应明确实际包含的分组/数量，并给出 GitHub Releases 入口；在完整版正式发布前不要写成“已可下载”。

工具输出卡数、牌组数、媒体数、文件大小、输入/输出 SHA-256 和字段保留结果。导入精简包不会从已有集合删除基础词或超纲词；建议用独立空资料档案导入，检查说明/正反面/媒体，再上传。APKG 压缩体积不能证明整个账户低于 AnkiWeb 集合限制。

## 验证边界

源码检查覆盖精确搜索、口音和来源限制、缺音回退提示、旧 WebView 升级、来源变化拒绝旧释义修正、wheel 资源和精简导出。生成的精简包还需要实际 Anki 导入和媒体检查；DOM 自动化不等于 AnkiMobile/AnkiDroid 真机验收，也不等于 AnkiWeb 实际上传成功。

此前本地交付的 1,892 张说明+必考词卡包经过独立导入/重复导入/媒体检查；该单次交付不意味着本 PR 已公开其二进制，也不意味着本工具能从未处理的 CSV 重做全部词典、词源和压缩资源。完整版的单次紧凑编码优化仍属于本地构建产物，本工具直接保留输入包中的共享资源和紧凑字段。
