## Findings corrected during review

- **Stale CSV text overwrite and review-flag clearing:** The initial CSV content hash omitted translation state, and a disposable reproduction replaced a newer human translation with text from an old CSV. Another reproduction cleared a later `manual_review` flag on same-text replay. `anki_pipeline/translations.py:7,14-15,60-67` now exports/checks `translation_revision`; a revision-mismatched same-text replay exits without an update. Regression tests cover both cases.
- **Destructive report path alias:** Initially, `check --report <configured database>` replaced the SQLite file with JSON in a disposable reproduction. `config.py` and `_guard_output` now constrain resolved output paths, and `_write_text` atomically replaces reports and preview rather than writing through an existing hardlink. A repeat reproduction rejects the active DB path and leaves its `SQLite format 3` header intact.
- **Enrichment preservation and missing-audio selection:** The initial Oxford predicate could not reach a missing MP3 when its filename and phonetic were nonblank; Youdao/Oxford could overwrite unrelated nonblank manually edited fields. `cli.py` now checks media state when selecting Oxford cards and fills only blank database fields. Safety tests cover both cases.
- **Missing legacy translation snapshot:** Migration previously defaulted a missing `Translate-tmp-1` row to an empty dictionary, silently yielding zero structured sentences. `migration.py:52-54` now stops with a clear error. The actual legacy input has all 1,960 snapshots.
- **Explicit forms and metric wording:** Migration, PDF extraction, and reclassification now pass parsed dictionary forms into exact matching. The quality metric now says `cards_with_at_least_one_complete_example`, matching its calculation. All 1,700 nonempty legacy `word_forms` values yield at least one parsed Chinese-labeled form. English provider labels such as `plural` remain outside `forms.py`'s accepted labels and should be treated as a future input compatibility limit.
- **Reclassification transaction:** The sentence read, acceptance calculation, and update now occur inside one immediate write transaction (`pipeline.py:143-160`), so it cannot overwrite a concurrent review change computed from a stale pre-lock snapshot.
- **Archived media recovery:** The optional package branch no longer requires the raw audio directory. It validates archive indices and member names, caps total uncompressed media at 256 MiB, checks existing targets including dangling symlinks, and refuses invalid existing MP3s without overwriting them (`pipeline.py:14-23,51-119`). A disposable full recovery copied all 1,960 referenced files from the 56 MiB archive; the legacy DB hash remained unchanged.
- **Media consistency and preview size:** The raw-copy fallback now rejects invalid or symlinked existing target media without overwriting them (`pipeline.py:33-42`); `quality_report` checks MP3 headers and a 5 MiB bound (`quality.py:19-25`). The packager also caps an MP3 at 5 MiB before embedding it in a self-contained preview (`packaging.py:68-90`). The trial archive's largest mapped member is 30,824 bytes.
- **Export path documentation:** `docs/OPERATIONS.md:21-22` now uses ignored `output/` CSV paths, matching the project's output guard. The runbook also names the `translation_revision` column used to prevent stale edits.
