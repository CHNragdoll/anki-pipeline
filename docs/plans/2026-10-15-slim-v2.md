# Further lossless full-package optimization

Authorized scope: reduce duplicate storage and opening/answer rendering cost while retaining every visible front/back text, style, control, audio byte, count, review explanation, note/card identity and learning state. Original packages, source databases and the user's Anki profile remain untouched. Outputs use a new owned directory.

1. Measure source byte distribution and exact repetitions. Prefer a shared literal-token bank with bounded dictionary size, plus external copies of exactly repeated iframe CSS/JS. Keep original script order and iframe content; do not reinterpret vocabulary or statistics.
2. Add a literal-only, offline codec with complete byte inverse, bounded and validated references. Inline first examples and sense summaries remain unchanged. Preserve current generation/disposal, media SHA verification, grouping and native-history behavior.
3. Build derived databases and media from the sealed v1 packages. Verify all transformed fields against v1 and then against the original semantic source; verify unchanged unrelated fields, cards/revlog/graves, audio and original resources. Never overwrite a handed-off package.
4. Consolidate an independent review of the actual changes. Seal both packages only with current code pins, reference closure and full byte-inverse evidence.
5. Repeat isolated actual native original/update/repeat imports and all media hashes, followed by actual rendered front/back interaction and speed checks. Browser evidence remains separate from physical-phone Anki acceptance.
6. Save local Git checkpoints and deliver both full APKGs with measured sizes and verification boundaries. No remote publication is authorized.
