# 同一局域网访问预览

当前书架地址是 `http://192.168.3.5:8771/`。手机与 Mac 连接同一局域网，Mac 保持开机；书架的红宝书“浏览全书”在 LAN 入口中指向最新义项频次预览。8771 下的其他页面、资源及下载沿用原路径。

整卷、原版及 LaTeX 读卷使用 `http://192.168.3.5:8765/`，卡片中原有的本机读卷地址在传输时替换为 LAN 地址。原文、翻译、审查哈希和磁盘上的预览文件不改变。原本的 localhost 服务继续运行。

在原有 8771、8765 本机服务启动后运行：

```sh
.venv/bin/python -B -u scripts/serve_preview_lan.py --bind 192.168.3.5 --network 192.168.3.0/24
```

若 Mac 的局域网地址改变，使用新的地址及对应子网重新启动。该脚本不负责开机自启动。停止此脚本即可关闭新增 LAN 监听，原有 localhost 服务继续运行。

LAN 转发保留原端口、路径、查询参数及静态资源行为；学习提交仅允许本入口的同源 JSON 请求及原有自定义请求头。不会在启动时导入卡包或更改进度。私有脚本、数据库、隐藏文件路径及路径穿越请求拒绝转发。

本次验证包括两本最新预览、书架入口、搜索、翻面、实际录音播放、整卷加载、资源与 HEAD、请求来源守卫。Mac 浏览器通过 LAN 地址的验证不代替用户手机的实际连接确认。
