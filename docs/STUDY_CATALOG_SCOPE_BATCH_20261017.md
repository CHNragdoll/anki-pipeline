# 现有书籍的统一板块登记

三本现有书的显式映射保存在 [library-scopes.json](../data/study-catalog/library-scopes.json)。
这是一份待应用配置；本节点没有修改正式主库。后续数学、雅思等资料继续使用同一登记接口，
不从书名或标签推断学科，不为不同板块建立另一套数据库或生成逻辑。

`study_catalog_library.classify_many(target, changes, expected=..., backups=...)`
先保存一次完整总库备份，再用同一个事务和原分类写锁登记所有选定书籍。
每本书必须提交精确的原 scope，`null` 表示尚未登记；任何书缺失或期望已过期，全部拒绝。
输入在备份前深拷贝，所有书及期望在首次写入前核对；未选书的登记保留。
原 `classify` 单书 API 不变。恢复应进入新 schema 并核对，不能自动覆盖期间新增的数据。

8 项真实隔离 PostgreSQL 测试通过，覆盖一次备份及真实恢复、写入中断整批回滚、
备份期间 CAS 失效、并发同一期望只有一个成功、未知书拒绝、输入突变和幂等重试。
测试只使用随机 `testcatalog_*` schema；不代表正式主库已经登记或学习服务已经切换到 PG。

正式应用还需：使用当前已复核的备份版本，核对正式书籍身份和原登记，执行配置，
再核对共同导出目录的 scope 及按“英语／考研”筛选三书的结果。此配置不创建未提供的未来书籍。
