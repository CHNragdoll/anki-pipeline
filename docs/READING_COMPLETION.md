# 真题例句的英文标记与答案回填

按用户 2026-10-01 的最终选择，中文译文保留普通文字，不再通过逐词或短语索引给中文加高亮。英文仍匹配原词与词典明确记录的屈折变化；原词形、同形异义排除、完形下划线和原句跳转继续生效。

完整原句的现成译文直接保留。阅读题干的空位先按结构化试卷明确记录的正确选项回填，回填的英文答案加下划线；对应的完整译文保存在派生数据中，不覆盖原始翻译或试卷。原题干与正确选项的既有译文作为核对依据，回填后的句意另经独立审校。

阅读题的非裸词选项也保留完整问题：有空位的题干填入当前候选项，并给插入部分加下划线；没有空位的题目分行展示原问题与候选项。来源注明题号和 A/B/C/D 身份，错误选项仍是候选项，不改称正确答案。正确项复用已审校的完整译文；其余 2,614 条新组合逐条译写并独立审校，显示为完整一段中文，不显示题干、选项标签。来源使用原卷真实层级，以 ➫ 连接。

Part B 句子插入题按明确答案回填，复用已审校选项及片段译文。纯空位与包含前后文字的空位都保留插入范围的下划线，原选项的句子位置与原题干位置分别绑定。

## 数据与绑定

- `data/reading-completions-v1.json` 使用 `reading-question-completions.v1`；当前范围为 44 套试卷、695 道阅读题干。
- `output/reading-option-context-review.json` 记录 880 道阅读题中 3,251 个可展示选项的完整题干及来源；269 个裸词选项继续不单独展示，但原题词频仍计入。显示时，补回题干与原选项中当前单词及词典已声明的屈折形式都加英文标记；原选项的来源命中范围、跳转坐标及原题词频保持不变。
- `data/reading-option-translations-v1.json` 与对应 `.review.json` 保存 2,614 条完整候选译文；加载时核对完整来源、作者和独立审校文件哈希，另 637 条既有已审正确项译文保持不变。
- 卡片直接复用现成 chunk 范围：电脑悬停、手机和平板点击查看对应，再次点击或点空白处取消；默认中文无高亮，新组合没有现成对应范围时保持普通文字。
- `output/sentence-insertion-completion-review.json` 记录 33 个 Part B 句子插入空位及其已有译文引用，独立组合审查记录在 `output/sentence-insertion-semantic-review.json`。
- 通过来源块关联题目，要求唯一题目、明确答案、唯一选项、来源网址、捕获时间及一致的题号答案令牌。不能只靠题号、相似题干或猜测建立关联。
- 每条派生记录绑定原始英文、译文、审校索引、结构化试卷、正确选项及源位置哈希。未知字段、缺行、重复 ID、未审校译文、残留空位或过期输入都会阻止生成。
- 相邻的 `data/reading-completions-v1.review.json` 绑定已审校侧车的完整文件哈希及全部句子 ID，审校报告另绑定实际审读的作者文件。译文在批准后改变，必须重新审校，不能自动套用旧批准。
- 原句跳转使用原已发布索引的句子与哈希；新增目标词来自答案时，跳转绑定原正确选项。显示文本的坐标与原卷的坐标分开校验。
- 词频按原题印刷内容统计，不把人工回填的新词再算一次。

## 验证与恢复

回填和中文普通文字的包装使用同一生成路径，因此网页预览与 APKG 同步。检查记录位于 `output/reading-completion-review/`、`output/reading-completion-code-review.json` 及 `output/reading-completion-delivery-verification.json`。

修改范围的备份位于 `backups/english-only-completion-20261001-133318`。源 SQLite 仅记录校验值，没有写入。需要恢复时先核对备份后的用户改动，不覆盖无关文件。旧不可变网页版本继续保留。
