# 统一学习资料总库：实施计划与当前状态

工作分支 `feat/unified-study-database-20261015`，基于已合并 `68b86a3`。
本批为本地功能改造，`type=feature`、`risk=R2`。用户授权新分支实现 PostgreSQL 总库、
统一 Anki/网页逻辑和关键节点 Git；没有授权本分支自动推送、PR、合并、发行、切换旧书架或写真实 Anki 集合。
命令见[操作说明](UNIFIED_STUDY_DATABASE.md)，可核对的范围与摘要见[本阶段验收记录](STUDY_CATALOG_ACCEPTANCE_20261015.md)。

## 目标和不变项

- 总库覆盖全部学习板块；考研英语、雅思、数学是分类和来源元数据，不是不同数据库或生成器。
  词汇、句子、题目、公式、图片/音频均可保留原字段；无 Word 字段及多模板卡使用共同投影。
- 共用资料、书籍/版本、单元、原书顺序及映射分离。新增书只配映射，复用已有内容；
  不为 2026、2027 或其他书复制判义、计数、模板修补或打包分支。
- 原词典条目及详细依据、双语原句、实际 target、chunk、语义归属、完整审核/转归历史、
  媒体原字节与各书文件名保留。不同词典、义项、大小写和词形不凭拼写相近强并。
- 原 note GUID、note/card/model/deck ID、字段与排序保留。公共内容身份与 Anki 身份分开；
  新书有自己的合法 ID 与未学习状态，已有学习状态由客户端管理。
- 同段同义合并展示，物理次数独立；完形只计正确答案回填正文，阅读保留全部候选及来源状态。
  转归内容进入正确词条对应句子，完整旧依据仍能查看；`as` 来源异常继续标记。
- SQLite 仅作历史只读输入及 Anki 规定的封包格式。原库、封存包、原文件及已发布附件不覆盖；
  PostgreSQL 用专用普通账号，不改其他数据库、认证或网络监听。

## 当前实现节点

1. **资料与快照**：全部指定源实际迁完；大表按稳定输入/已提交序号续传，building 状态阻止输出与编辑。
2. **共同投影**：两宿主共用数据、事实、模板和资源版本。未修订基线已证明三包每个 ZIP 成员未压缩字节相同。
   导出不依赖原包或旧业务 SQLite 继续存在；它们保留作只读回退与来源证据。
3. **正式修订**：词典释义、原句/译文/chunk、单位置义项和词条转归均走完整 CAS 范围、共同写锁、备份与事务。
   任一书缺目标、旧摘要过期、候选/来源证据失效或正文无法保留，全部拒绝；不只更新 HTML 或当前一本书。
   当前字段正文、查询事实和原生 Examples 共同更新；历史原条目与完整审核继续保留。
4. **版本及后续书**：note/model/运行时版本在同秒连改与 A→B→A 时仍单调推进；媒体依赖和别名一次应用，
   新映射书继续读取同一底层语义版本。来源修订链保持平坦；25 次链增长与 22 次隔离 PG 实际提交分别有证据。
5. **来源与板块**：数学无 Word 双模板与雅思映射已做隔离测试；新增 `study:<namespace>:<source-key>`
   支持考试、书籍、文章、课程等显式来源，不改旧考研封印，也不从标签猜年份。
6. **同段展示**：已加入共同原生例句分组与修订 hook，只按同来源和正式共同义项证书合并；不同义项继续分条。
   原成员跳转证据、每个 target、双语细块及物理次数保留，不用整段粗块代替原分块。
7. **实际客户端**：三完整 APKG 均在临时原生集合更新和重复导入；本批没有修改实际用户档案。
   数学原生导入及此前会话 Safari 公式观察按样例记录；三本全量网页和后续导航/性能属于单独验收范围。

以上语义写入能力的验证发生在隔离测试 schema；没有把测试释义、句子或转归写入实际三书主库。
当前 master 仍沿用已封存内容，源 `as` 异常未被静默消除。

## 存储与维护约束

本机总库使用 PostgreSQL 17 的 `anki_study_catalog` / `study_catalog`。
原语义 SQLite 约 21 GB，迁移不先复制整个库，也不删除原库和历史腾空间。
精确内容按 SHA 共享，文本按需无损压缩，媒体不重编码；文件名在各书映射中保留。

macOS 的未分配空间与含可回收空间的可分配容量不同。本次约 90 GB 的重要用途可分配读数仅是当时观察，
不能当作预留保证，更不能只凭较小的 `df` 数字要求用户清理指定容量。
临时依赖/源码快照及非 iCloud 导出目录用于避开按需取回和大量小文件排队；没有改变系统设置。
PG 快照、对象摘要、历史行流和恢复结果分别核对；迁移前空库基线不能替代完整库恢复。
