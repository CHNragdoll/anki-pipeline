# 统一学习资料总库

工作分支：`feat/unified-study-database-20261015`，基础为已合并的 `68b86a3`。
用户授权在新分支实现总数据库，并在关键节点提交 Git；本批为本地数据改造，
`type=feature`、`risk=R2`，不包含自动合并、发行、切换线上书架或写入真实 Anki 集合。

## 目标与保留规则

- 总库覆盖全部学习板块，考研英语、雅思、数学均为学科/考试元数据；不按板块另建库或复制生成器。
  通用学习条目可以是词汇、题目、公式、图片/音频内容；词汇义项审核是其中一个内容适配器。
  新书通用映射不得强制有 Word 字段；正向/反向等多模板卡在 Anki、网页均按实际卡片完整导出。
- 同一总库保存词条、各词典原始释义与详细依据、双语原句、实际目标位置、chunk、
  义项归属、完整审核与转归历史、书籍目录、现有卡片身份、模板和打包资源。
- 书籍/年份 → 单元/分组 → 原书顺序及词条映射。新增书籍复用现有公共资料，
  不再为相同词条、原句或媒体复制一套公共数据库。
- 公共资料具有稳定身份和可核对的版本；不同词典、不同义项及各书独有内容保留来源和映射。
  `train`/`training`、`US`/`us`、`May`/`may` 等不能按拼写或词形猜测合并。
- 保留各书原有 note GUID、note/card/model/deck ID、字段、顺序和附加身份；
  共用资料身份与 Anki 导入身份分开。学习进度不是公共词库数据，不写入用户集合。
- 同段同义展示合并与物理出现次数继续分开；完形/阅读口径、校勘及 `as` 标记保持。
- 原数据库、封存包、原始文件及已发布附件只读。迁入不同路径，失败不切换现有入口。

## 实施节点

1. **库结构与恢复边界**：版本化 PostgreSQL，公共词条/资源/来源及书籍映射，内容去重与无损压缩，
   事务、幂等输入标识、验证、只向新路径恢复；小样本验证通过后提交。
2. **实际资料迁移**：以当前完整包、词条数据和最新义项审核库为输入，流式保存当前状态及历史。
   记录输入封印、全部原始行、媒体字节和目录映射；输出每书、每表及每字段对账报告后提交。
3. **统一读写与生成**：公共内容修订与历史、跨书投影、词频查询、数据库独立的 APKG/网页导出。
   从同一数据库生成三套书；保留每本书模板和身份，不依赖旧包继续存在后才能读取正文。
4. **完整校验与交付**：源输入未变、映射及计数一致、字段/资源可逆、重复迁入不重复计数、
   失败事务回滚、备份恢复、代表网页交互与 Anki 更新路径；集中审查实际 diff，记录未验收范围。

## 数据与空间

目前最新义项审核库约 21 GB。macOS 的未分配空间和可回收后可分配空间不同，
2026-10-15 复核重要用途可分配约 90 GB；容量是动态参考，不是预留保证。
空间检查同时使用文件系统未分配容量和系统重要用途容量。不要先复制整个大库再迁移，
也不删除历史库腾空间。新库按稳定内容摘要共享重复资料，对大型文本使用无损压缩；
媒体原字节按摘要只存一次，原文件名作为每书资源映射。迁移前估算并在过程中检查空间。
维护者明确指定总库使用 PostgreSQL，旧 SQLite 只作为只读输入和 Anki 规定的封包格式。
使用本机 PostgreSQL 17 的独立 `anki_study_catalog` 数据库及普通专用账号；
不改变原有服务的权限、认证或网络监听，也不连接其他业务库。
未修改的原输入本身是回退基线；已有总库后，在一致性快照内备份，
恢复到新数据库或新 schema 并逐项对账。备份记录明确标识 PostgreSQL，不能套用 SQLite 文件备份。

## 完成证据

维护者补充要求：Anki 生成必须统一。使用同一个生成入口、校验器、公共模板/交互资源
和封包实现；书籍通过映射和来源内容配置进入。不得为红宝书 2026、2027、刘晓艳
分别复制代码或添加按书名分支的补丁链。旧模板完整留作历史来源，原有 Anki 身份不改；
公共展示规则的接入须核对正文、计数、chunk、审核、音频和原有交互，不能只证明能生成 ZIP。
网页版同样只有一条公共生成链：与 Anki 共用总库读取、内容投影、计数和公共展示规则，
书籍目录和原书排序作为配置传入。网页端与 Anki 端仅保留宿主所需的适配，
不得分别计算义项/词频或维护按书籍复制的页面修补流程。

不能用空表、导入脚本或结构测试代表完成。必须有真实总库、全部书籍目录和当前内容映射、
完整审核历史、媒体、可运行查询/修订/导出命令，以及从总库生成的可核对产物。
报告数据库路径、版本、书籍/单元/词条/原句/实际位置/审核/资源计数、具体 Git 节点、
输入不变及恢复证据。网页、原生 Anki 和手机分别报告实际观察，不扩展历史样本的覆盖范围。
