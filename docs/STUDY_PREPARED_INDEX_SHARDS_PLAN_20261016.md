# 完整卡索引的小块交付：隔离验证计划

目标仍是首次选卡和完整翻面快速响应，保持全部原句、义项、chunk、审核历史、计数和学习状态。
当前正式入口维持v18。本计划先制作独立QA，不直接替换原入口，不生成APKG或写PG。

## 当前依据

2027正式prepared index为4,435,220字符，当前先完整下载、校验、解析，才取其中一张卡的规则。
既有v18阶段样本中该索引文本于83ms到齐、SHA于469ms完成；间隔含调度和worker启动，不能视为纯计算耗时。
它的全部卡片规则可以按确定的card ID摘要分组，根只封存各组摘要，选卡时按需读取对应一组。

本轮同口径一次对照：当前正式顺序正面1745ms、立即背面2069ms；改为正面后获取完整资料为469／2555ms。
固定模块预取候选为802／2834ms。三者完整内容8项对照通过，但缓存和系统负载不恒定；
这些结果只说明存在等待取舍，不足以宣称任何方案已让两面全部秒开。两个候选均未进入产品源码。

## 隔离协议

1. 保留原完整index及SHA。读取它并核对原pin后，按`SHA256(card_id的UTF-8字节)`前2位十六进制分为至多256组。
   不按书名、年份或学科分支，所有卡片的原rule逐字段保留。
2. 新根`study-prepared-shards.v1`记录原index SHA、总卡数和每组的URL／SHA／卡数；
   小块`study-prepared-shard.v1`记录同一原index SHA、组前缀和原cards映射。使用内容寻址文件。
   builder逐一还原全部映射并与原index精确比较，再允许生成QA入口。
3. HOST保留内联prepared与旧`study-prepared-index.v1`路径。新根和每个小块均经原deliveryArtifact校验，
   再核schema、原index绑定、前缀、条数和每个成员的确定分组；未知卡仍按既有兼容路径处理。
   不把某个小块的校验代替正文、完整artifact、wrapper、双面、base、模块或native校验。
4. 原卡缓存4项／16MiB、邻卡2MiB和SHA worker各上限不改。新增索引小块缓存最多4项、合计1MiB，
   单块解压最多256KiB；错误不得污染缓存。新根替代原整本索引的常驻映射。
5. 新index根作为既有deliveryBinding的快照pin；front/full仍须同一根。原卡front/full artifact字节、
   原wrapper、media、catalog、PG与APKG均保持不变；不修改完整背面就绪门槛。

## 验收和采用条件

- 原HOST失败重现与新HOST合同：旧协议、根／小块错SHA、错schema、错来源、错前缀／条数、未知卡、
  单块过大、并发共享、失败重试、缓存限额、取消和A→B→A，完整卡错配仍拒绝。
- builder证明全部rule还原相等，原输入前后SHA／stat不变；只在独立QA创建新根、小块和入口。
- 先实际运行同口径长卡，与当前正式逻辑比较正面、立即完整背面和总时间；
  626条主例句、688次物理出现、1716历史HTML摘要多重集、1144历史ID引用、可见全文、native ready均须保留。
- 只有收益明确、完整内容通过和独立实际diff复核后，才接入共同factory；随后才做三书条件推广与当前安装验证。
  若只把等待转移到另一面或收益不足，保留证据并停止候选，不为通过测试降低完整性要求。

本文件是下一步已授权实现范围，不是完成证明。Safari／真实手机实际性能仍须单独确认。

## 隔离验证结果：未采用

2027书的6,532条原rule已逐条重构并保持原顺序序列化相等。根为52,124字节，
`more`所在小块为17,124字节，首次规则读取合计69,248字节；原完整索引为4,435,220字节。
读取量减少不等于翻面时间按相同比例减少。

真实隔离页的单次结果是正面1,468ms、正面提交后立即完整背面2,641ms、首次请求至完整背面4,110ms。
626条主例句、688次物理出现、完整历史HTML摘要多重集、历史ID引用、可见全文、元素数、native状态等
8项对照均与原v18相等。记录在
`output/study-catalog-20261015/v18-prepared-index-shards-actual-ui-v1.json`。
该页保留原FRAME和就绪门槛；它是一次隔离样本，不能据此计算稳定提速率，也不能当作Safari或手机验收。

独立复核发现读取小块期间变更root时，v1未覆盖所有快照变更反例。
v2已在root、卡ID摘要和小块读取后复核入口时复制的原始字段；6种快照反例均被拒绝，
合计60项协议及HOST合同通过。v2仅dry-build，未安装或运行浏览器；不将v1的实测结果归给v2。
当前生产配置封闭不可变，该缺口未被判为现有用户路径的P1/P2，但不能宣称任意动态配置均已验证。

**采用结论：停止本候选，不接入共同factory，不推广三书。** 完整性证据通过，但未取得明确性能收益；
正式入口仍为v18。原卡、索引、媒体、PG、APKG和学习记录未变。
首次极端长卡立即翻面尚未全部秒开，README继续明确保留这一未完成项。
