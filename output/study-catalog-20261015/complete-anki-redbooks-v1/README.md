# 两年红宝书完整新包：本地核验节点

两包已完整导出，尚未交付或替换正式 Release。2026 899.6 MB、2027 820.6 MB，分别大于旧包399.0／354.1 MB，**瘦身目标未通过**。

- [归档核对](archive-parity.json)：实际最终APKG、原字段raw exact、原媒体原字节SHA、SQLite身份／卡调度／复习日志逐行核对；仅显式记录从原字段重算的派生checksum/sort缓存。
- [2026原生导入](native-2026.json)、[2027原生导入](native-2027.json)及[明确导入选项](native-2027-options.json)：合并笔记类型、始终更新笔记、保留调度；重复导入保持身份／学习状态；导入文本只允许Anki自身NFC规范化，和归档raw exact分开。
- 默认不合并时会保留旧类型；只合并时也出现空的新字段，不算更新成功。尚不建议用户直接用默认选项更新现用集合。
- [大小组成](size-breakdown.json)按实际ZIP成员分类，原媒体未删除；新增完整HTML/profile/packet是本版增长的主要来源。
- 真正Anki窗口的正常刷卡及浏览直接预览、手机、首翻速度仍分别待验，非空模板字符串不替代这些检查。Mac锁屏时停止UI操作，等待手动解锁。

[15项独立校验器测试](../../../tests/test_study_compiled_apkg_parity.py)的直接执行和unittest discover均通过；覆盖原字段、GUID/模型/卡身份、调度/日志、实际原媒体、载体及新增缓存例外的拒绝条件。

本轮没有推送、PR、合并或更新发行附件。GUI工具曾在退出隔离实例后意外重新打开普通Anki并显示自动同步，已立即关闭，没有向普通profile导入测试包或手动编辑／评分；不能宣称整个会话从未打开普通profile或其文件绝对没变化。
